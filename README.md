# Infinite Tic-Tac-Toe

A deep, competitive, and replayable strategy game inspired by Tic-Tac-Toe.

## Features

- Infinite 3×3 sliding mode
- Progressive expanding board mode
- Shared game engine (web + mobile + server)
- Deterministic logic with unit tests

## Tech Stack

- TypeScript
- pnpm + Turborepo
- React / React Native (planned)
- Node.js backend (planned)

## Structure

apps/ → web, mobile, server  
packages/ → shared game-engine
